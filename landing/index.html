FAQ ❓

Questions, answered 🙋

🔒 Is it really telemetry-free?⌄

Yes — and verifiably so. Sharing and auto-update channels are force-disabled in config, the audit is public (docs/telemetry-audit.md), and the only network traffic is your local core and the provider you configure.

🔌 Which AI providers are supported?⌄

75+ out of the box: Anthropic, OpenAI, Google, xAI, OpenRouter, local Ollama, and any OpenAI-compatible endpoint. OAuth login for Claude Pro / Copilot-style accounts, plain API keys for everything else.

📦 Do I need to install OpenCode separately?⌄

No. The desktop app ships a supervisor that downloads the pinned core, runs it on a random loopback port with a generated password, health-checks it, and tears it down on exit. One installer, zero terminal.

🗝️ Where does my API key live?⌄

In the core's own credential store (auth.json), written by the core itself. The UI never stores or even sees a second copy.

💻 Which platforms are supported?⌄

Windows 10/11, macOS 12+, and Linux (AppImage / .deb / .rpm). Apple Silicon and Intel both supported.

🆚 How is this different from Cline or Kilo Code?⌄

They are IDE extensions with their own lighter agents and telemetry. BuzzAgent is a standalone desktop app over the full-strength open core — no IDE required, no account, no telemetry, and native extras like worktrees and the browser loop.

💸 What does it cost?⌄

Nothing, ever. MIT licensed — free for personal and commercial use, forever. You pay only your LLM provider directly, at their rates, with no middleman markup.
